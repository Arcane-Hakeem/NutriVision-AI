==================================================
NUTRIVISION AI - PROJECT OVERVIEW (FRONTEND)
==================================================

1. WHAT IS THIS PROJECT?
NutriVision AI is a smart nutrition assistant. Users upload photos of their meals, 
and the application identifies the food and estimates its nutritional value.

2. WHAT HAS BEEN BUILT SO FAR (FRONTEND)
The entire frontend UI is complete and fully responsive. It includes:
- Dashboard: Daily calorie/macro stats and a weekly area chart.
- AI Food Scanner: Upload interface that previews the image and is ready to send it to the backend.
- Nutrition Analytics: A bar chart displaying weekly trends for Protein, Carbs, and Fats.
- Meal History, Food Library, Settings: Styled UI pages.
- Layout: Fully responsive sidebar navigation and header.

3. TECHNOLOGY STACK USED
- Framework: React (via Vite)
- Styling: Tailwind CSS v4 (Custom Forest-Green theme)
- Routing: React Router DOM
- Charts: Recharts
- Icons: Lucide React
- API Requests: Axios

4. HOW TO RUN THE FRONTEND LOCALLY
Prerequisites: Node.js must be installed.
Step 1: Open terminal in this folder.
Step 2: Install dependencies (only needed the first time):
        npm install
Step 3: Start the development server:
        npm run dev
Step 4: Open the URL shown in the terminal (usually http://localhost:5173).

5. NEXT STEPS (BACKEND INTEGRATION)
The frontend is currently using "Demo Data" for the charts and dashboard. 
To make the AI Food Scanner work, the backend developer needs to:

- Run the backend (Python FastAPI + OpenCV) on: http://127.0.0.1:8000
- Enable CORS to allow requests from: http://localhost:5173
- Create an endpoint: POST /analyze
- Accept a multipart/form-data file upload with the key "file".
- Return a JSON response EXACTLY matching this structure:

{
  "food_name": "Apple",
  "confidence": 0.95,
  "calories": 52,
  "protein_g": 0.3,
  "carbs_g": 14,
  "fat_g": 0.2
}
